# graffiti-expressionist-image-transform
 Transform an ordinary supplied image into a vivid neo-expressionist graffiti abstraction. Use when a user asks for a Basquiat-inspired feel, energetic hand-drawn linework, symbolic marks, fractured anatomy or space, raw painted texture, and bright high-contrast color while retaining the input image's recognizable subject and composition.
# Graffiti Expressionist Image Transform

Use ImageGen for every transformation. Treat the user's source image as the required subject/composition reference. If an additional reference image is supplied, analyze it only for broad visual traits; do not reproduce its exact layout, individual motifs, text, or signature.

## Fixed visual recipe

Preserve the source's principal subject, silhouette, pose, camera angle, and scene hierarchy. Then apply all of the following:

- Replace polished contours with assertive, uneven black charcoal/ink outlines, doubled contours, scratches, hatching, and visible corrections.
- Abstract objects and anatomy into overlapping planes, expressive distortions, cutaway-like compartments, and loosely assembled geometry; keep the subject identifiable.
- Add a restrained layer of universal graffiti-like visual language: arrows, crosses, tally marks, loops, boxed fragments, strike-throughs, crowns, teeth, eyes, bones, and diagrammatic marks when fitting the subject. Use non-lexical marks or invented illegible glyphs—never readable words, names, logos, or signatures.
- Build a saturated palette around electric cyan, ultramarine, scarlet, cadmium yellow, hot pink, orange, and deep black. Keep a few pale/raw canvas areas and imperfect brushy color blocks for contrast.
- Use raw mixed-media texture: dry brush, paint drips, scumbled pigment, crayon/oil-pastel scrawl, rubbed canvas, and collage-like overlaps. Prefer high energy and deliberate imperfection over clean vector geometry.
- Avoid photorealism, smooth airbrushing, ornamental elegance, legible typography, copied marks from the reference, watermarks, or a literal duplicate of a known artwork.

## Editing workflow

1. Inspect the source image and state the subject, the composition features that must remain, and any sensitive identity details to preserve.
2. If a style reference exists, extract only its broad visual rules: vivid blocks of color, raw gestural outlines, symbolic drawing, fragmentation, and layered mixed media.
3. Call ImageGen with the source image and a concise prompt built from the template below. Keep the transformation substantial, but do not substitute a different subject or scene.
4. For a revision, preserve the successful composition and adjust only the requested dimension (for example: more abstract linework, stronger cyan/red contrast, fewer symbols, or clearer face).

## Prompt template

Use this as the starting point, replacing brackets with the source-specific content:

> Transform the supplied [subject/scene] into a vivid neo-expressionist graffiti painting. Preserve [identity, pose, composition, and key objects]. Rebuild forms as fractured overlapping planes with bold irregular black ink/charcoal contours, doubled lines, scratches, hatching, arrows, crosses, tally marks, abstract diagram symbols, and a few non-lexical hand-drawn glyphs. Use raw mixed-media canvas texture, brushy blocks, paint drips, and layered crayon/oil-pastel marks. Make the palette intense and high contrast: electric cyan, ultramarine, scarlet, cadmium yellow, hot pink, orange, deep black, with pale exposed canvas. Energetic, imperfect, hand-made, and expressive; no readable text, logos, signatures, watermark, or copied layout from any reference image.

For landscapes, keep the horizon, major landforms, and focal figures recognizable, then use contour-like hatching and stacked painted fields. For portraits, retain face direction and distinctive features, but use intentionally fragmented planes and a strong contour hierarchy.
